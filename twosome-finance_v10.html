Download your data as a JSON file and send it to your partner (WhatsApp, email, etc.). They import it and your entries merge together.

How it works
1. You export → send the .json file to partner
2. Partner imports it → entries from both merge
3. Partner exports their merged file → you import
4. Both devices now have the same data ✓
